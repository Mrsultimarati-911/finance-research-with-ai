# 自制资料输入

这八份小材料用于“仅本地资料快查”请求，日期为2026-10-05。数值均为虚构，不能用来说明现实银行的AI效果。输入任务和成果导航见[案例说明](../README.md)。

- [topic.md](topic.md)：主题、耗时与缺失材料。
- [metrics_old.md](metrics_old.md)、[metrics_new.md](metrics_new.md)：初稿与修订稿。
- [research_note.docx](research_note.docx)：正文与顶层表格。
- [research_data.xlsx](research_data.xlsx)：公式、隐藏行与隐藏工作表。
- [records.csv](records.csv)：带换行的字段及缺失值。
- [mixed_report.pdf](mixed_report.pdf)：文字页与自制扫描页。
- [analysis.py](analysis.py)：只作文本阅读的简小代码。

公开副本将稿件称谓统一为初稿和修订稿。PDF扫描页重新排版并保持相同内容；42仍是待人工核对的虚构人数。
