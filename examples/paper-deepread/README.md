# paper-deepread 使用案例

任务：从论文精读推进到问题讨论与研究设计。以下案例保留实际材料状态、学术来源和讲解算例，日期为2026-10-05。

| 案例 | 示例请求与成果 |
|---|---|
| [四种笔记结构](four-structures/README.md) | 用同一竞价论文比较原文章节、研究逻辑、两层阅读与自定义五部分 |
| [答疑与论文延展](discussion-extension/README.md) | 解释报价分歧和买压，再设计报价分散分解研究 |
| [中文变量公式解读](ai-productivity/README.md) | 拆解企业AI、生产率与劳动力技能结构变量 |
| [理论与实证衔接](cash-flow/README.md) | 用两种结构读错误估值与内部现金流论文 |

使用时提供自己有权阅读的论文PDF或公开论文入口，并把任务和结构要求写明。案例中的原论文PDF、全文提取、原图与页面截图不再分发；笔记保留来源链接及图表页码。未取得的附录、数据与代码均在各案例中明确说明。
