# 同一论文的四种精读结构

任务：阅读买方报价分歧与股票收益论文，比较四种笔记组织方式。日期：2026-10-05。

示例请求：“用 paper-deepread 精读这篇论文，分别按原文章节、研究逻辑、全文总览与逐章详读，以及全文总览—变量拆解—理论模型—结果分析—结论组织。”

| 成果 | 内容 |
|---|---|
| [按原文章节](01_按原文章节精读.md) | 沿作者章节解释变量、公式及证据 |
| [按研究逻辑](02_按研究逻辑精读.md) | 集中梳理问题、测量、设计与竞争解释 |
| [全文总览与逐章详读](03_全文总览与逐章详读.md) | 先建立全篇地图，再进入细读 |
| [自定义五部分](04_自定义五部分精读.md) | 集中拆解变量、模型与结果 |

来源：Zhang、Zhang、Guo，*Buy-side divergence of opinion and stock returns: Evidence from call auctions*，Finance Research Letters 99（2026），109927。[DOI](https://doi.org/10.1016/j.frl.2026.109927)。实际阅读13页PDF正文、式（1）—（5）、图1—3、表1—6及数据可用性声明；线上补充附录未取得，未重新估计回归。笔记中的算例与研究评价分别标明。原论文PDF和原图不随案例再分发，图表位置与来源链接保留在笔记中。
