## 商业银行AI应用与人才调整

任务：从商业银行AI应用与人才调整主题形成研究框架，再写初稿，并展示局部修订与审查。材料整理日期：2026-10-05。

示例请求：

1. “用 proposal-writing，以人工智能应用、人才任务调整与商业银行运营表现为题，先给研究框架，明确变量、竞争解释和数据条件。”
2. “依据这个框架和已有文献摘要写完整计划书初稿，缺少的数据权限、团队基础和指南不要补造。”
3. “只改方法段；按指定三章模板重组；审查资源和发表承诺是否有依据。”

- [研究框架](研究框架.md)：总问题、研究任务、机制、数据条件与讨论入口。
- [计划书初稿](计划书初稿.md)：十部分论证稿及来源。
- [模式与边界演练](模式与边界演练.md)：自制小输入与局部修改、补写、审查、模板输出。

文献输入见[商业银行AI研究版图](../academic-deepsearch/bank-ai/研究版图.md)。多数依据来自摘要和明确读取的公开文本，全文方法未全部核实。未提供正式申报指南、期限、团队基础、完整样本和内部数据授权；这些均保持待补，不把研究设计写成已经完成的事实。
