# Markdown 交付

默认中文 Markdown，沿用用户结构、读者和保存目录。快查使用[直接答案与证据](quick-search.md)，学术深检使用[六章报告](report.md)。

正文判断与来源表使用同一编号，保留来源、日期、版本、位置和读取范围。数字注明单位、时期与统计口径；作者观点、综合解释、假设和未知不能因行文或排版被混淆。

文件应实际保存并报告位置；关键链接和本地资源可回查，未读或不可访问材料单列。只保留摘要和必要证据，不复制完整论文或资料档案。用户只要求对话回答时不强制创建额外文件。

无法取得来源时交付当前证据、实际查询和未完成事项，不补造内容。本包交付范围为 Markdown，未提供Office、幻灯片或PDF生成器。
