# 请求示例

以下为聊天请求，方括号内容按任务替换。尚未安装时先要求读取本仓库的 skills/academic-deepsearch/SKILL.md。

```text
使用 $academic-deepsearch，只查[允许目录]，不联网。
找出与银行运营效率指标有关的定义，给文件、原始位置、片段和实际已读范围。
```

```text
使用 $academic-deepsearch，仅比较我提供的两版报告。
核对同一指标的数值、单位、时期和定义变化，区分口径差异与真实冲突。
缺少依据的原因写未知，输出中文 Markdown。
```

```text
使用 $academic-deepsearch，核对[政策解释]，仅使用我给定的公开机构网页。
先给答案，再列原文链接、章节、发布日期和生效条件；搜索片段不作为正文依据。
```

```text
使用 $academic-deepsearch，围绕人工智能应用与商业银行运营效率、人才结构做金融学术深检。
默认近五年加必要经典，先逐篇摘要，再按六章整理研究版图。
未读的方法细节标未知，保留候选和未处理项，输出到我指定的目录。
```

```text
使用 $academic-deepsearch，仅用附上的文献清单与摘要，不联网。
区分摘要和元数据，按研究问题比较结论，缺变量口径、识别或稳健性时明确未知。
```

```text
使用 $academic-deepsearch，只核对这份参考文献的题名、作者、日期、出处和 DOI。
给冲突和无法确认项，不补造标识，也不扩展成综述。
```

```text
使用 $academic-deepsearch，从我给出的 DOI 发现参考文献和后续研究候选。
逐项核对实际摘要，引用 ID 不当作已读详情，版本关系由真实材料确认。
```
