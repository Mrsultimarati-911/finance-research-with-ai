# 本地文件与上传材料定位

限定目录或文件后读取。上传材料无本地路径时用宿主读取并保留原始文件名，不能虚构路径。先列文件、格式与状态，通常排除依赖、缓存、构建和版本控制目录，并说明实际范围。

正文文本优先使用 rg 或 local_search.py，不只搜索文件名。命中后读上下文；PDF、DOCX、XLSX不能因 rg 未命中便判断没有内容。大文件按单位读取，保留未读部分。哈希确定本次读取版本，文件修改时间不代替材料发布日期。

## 正常格式的定位

| 格式 | 原始位置 | 注意事项 |
|---|---|---|
| TXT/MD/代码/日志 | 文件与原始行号 | 未执行代码不声称已运行 |
| PDF | 物理页与抽取位置 | 物理页从1计；抽取行不冒充原PDF印刷行号 |
| DOCX | 段落、标题路径或表格行列 | 不提供排版页码；正文抽取不覆盖所有批注、修订与文本框 |
| XLSX | 工作表与单元格 | 区分公式、缓存、隐藏内容和合并区域；不执行重算 |
| CSV | 记录、列及必要物理行 | 默认首记录为表头；无表头使用 --csv-no-header |

本地助手面向正常格式。破损、非标准或异常编码材料可能无法读取或被误读，抽取结果不构成格式完整性保证；重要数字、表头、单位和公式须回到原件核对。PDF扫描页或稀疏页可能无法形成可靠文本，本包不提供自动OCR，保留为待读或待核对。

DOCX结构位置不等于Word排版页码。XLSX公式与缓存分开，缓存缺失写未知，不将空值视为重算结果；无依据不判断缓存时效。CSV引号内换行不一定是新记录，破损引用格式需人工检查。

## 辅助程序

local_search.py 提供 inventory/search/read，check_evidence.py 用于本地回查。见[工具说明](tools.md)。证据记录哈希、获取时间和已读范围，材料改变后重新读取。

文本查询限同一原始行；跨行词组拆词发现后再读上下文。--start 从0计读取单位偏移，证据位置从1计。默认排除构建缓存目录，--include-excluded 仅在用户明确要求时使用。读取库缺失、加密、权限或格式问题据实说明，不将失败当无相关内容。
