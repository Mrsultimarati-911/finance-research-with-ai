# 默认中文 Markdown 报告

学术深检默认以下六章，用户指定结构优先。先写实际取得的逐篇摘要，再综合。资料快查使用[快查答案](quick-search.md)，不强制六章。共同规则见[证据规则](evidence.md)。

## 1. 研究问题、检索范围与获取情况

总问题、子问题、执行日期、时间窗口、经典补充、来源和实际查询、分页覆盖、候选与纳入/排除/待核实/未处理数量、停止原因。区分实际读取与尚未处理内容。

## 2. 逐篇文献摘要

使用稳定编号，保留题名、作者、出版日期及精度、出处、DOI或其他标识、真实链接和已读范围。只根据实际内容写研究问题、对象、方法、主要结论、主题关系和局限。变量、识别、稳健性与统计量在摘要中未说明时标未知。仅元数据记录不作为结论证据；读取全文时补实际章节或页位置。

## 3. 研究版图与演变脉络

按问题和机制组织线索，区分 AI 应用、一般金融科技、算法预测和劳动影响。说明经典与当前问题的关系；工作论文和发表版保留实际比较范围与差异。

## 4. 共识、分歧及证据边界

判断关联文献编号，区分作者结论、可获取证据和综合分析。方法、样本或变量差异无法核实时只给可能解释。不同地区、工具、代理指标及论文版本不混为独立支持。

## 5. 待核实的研究缺口与研究方向

列可检验问题、可能机制及下一步需要的文献和数据。表述为本次材料尚未回答的问题，不据有限摘要证明“首次”或全球文献空白。

## 6. 文献矩阵、参考文献及核实情况

矩阵保留编号、研究问题、摘要明确的信息、结论、相关性、来源/位置、已读范围、日期/版本/核实状态。参考文献只用真实字段，区分单源、多源和未确认；缺 DOI 保留真实链接，不补造。背景材料与论文分组，未处理候选单列。中文 Markdown 保存摘要与必要来源记录，不归档论文全文。
