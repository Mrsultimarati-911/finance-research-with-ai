# 金融学术检索流程

多源发现与身份核对方法参考锁定上游，来源见[来源记录](../PROVENANCE.md)。快查不强制学术报告结构。共享的来源和读取边界见[证据规则](evidence.md)。

## 问题、查询与时间

将总问题拆为研究对象、机制、结果及竞争解释，构建中英文词组。例如 artificial intelligence、technology adoption、commercial banks、operational efficiency、skill composition，以及人工智能、银行运营效率、人才结构和技能需求。区分 AI 实际应用、一般金融科技与算法预测研究。

以用户时区的执行日为基准，默认向前五个日历年，首尾包含；用户明确日期优先。只有年或月的记录与边界重叠时标日期待核实，不补为一月一日。入库时间不代替出版日。经典文献另标范围外补充。

使用 Crossref、OpenAlex 的公开资料及宿主公开搜索。中文材料补查期刊、大学和研究机构公开页。目录、题名和搜索片段只提供线索；未取得摘要不补写研究结论。

## 批次、筛选和引用链

每次查询记录来源、实际查询式、日期范围、页或游标、返回条数、下一页和状态。单页调用只处理已返回内容；继续分页时使用实际游标。未取得的页保留为未处理，不宣称已经筛选。分批阅读和写摘要，避免默默只读前十或前二十条。

区分纳入、排除及其理由、待核实和未处理。代表文献可追踪参考文献与后续引用；得到引用 ID 不等于读过详情，也不代表引用者支持原结论。

重复记录和版本由阅读者或宿主核对：同 DOI 或平台标识要核对元数据冲突；相近题名和跨平台无 DOI 记录不直接合并。工作论文与发表版须依据作者、文本或出版关系确认，保留各版本及差异，不重复计为独立研究。

## 补搜与结束

补搜由当前材料的缺口决定，可围绕未闭合机制、中文来源及代表文献引用链继续。阅读者结合实际查询、已读材料、剩余候选和问题判断是否结束，说明停止原因及未完成项；不使用自动饱和或自动完整覆盖结论。

访问受限、配额不足或来源响应异常可能中断查询。停止受限路径，继续范围内可用材料；全部无法取得时交付实际查询、失败原因和待补资料，不生成无证据综述。流程交付见[六章报告](report.md)。
