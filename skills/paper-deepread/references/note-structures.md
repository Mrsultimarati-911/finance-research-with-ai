# 笔记结构与解释深度

结构组织与分析深度分别处理：四种结构都应达到详细精读的标准，不能把“研究逻辑”写成短摘要。以下是可调整的组织参考，章节名依据论文实际内容变化。

## 一、按原文章节

沿用实际章节顺序和标题，包括引言、理论或假说、制度背景、数据与方法、结果、稳健性和结论中真实存在的部分。每章解释它承担的论证任务，将相关公式、图表及关键附录放在相应章节。

允许增加便于教学的子标题，但不把不存在的原文章节写成原文结构。

## 二、按研究逻辑

以研究问题 → 理论或经济机制 → 可检验预测 → 测量与样本 → 研究设计 → 核心证据 → 替代解释与稳健性 → 结论评价组织。必要时将原文不同章节的证据集中讨论，注明真实出处。

理论文章可调整为假设、模型构造、命题、证明、比较静态、适用边界。预测文章可按信息集、目标、模型、训练评估、样本外证据重组。

## 三、全文总览与逐章详读

先给全文地图，说明研究问题、理论机制、主要变量和方法、关键结论及证据位置。随后展开完整逐章详读。总览用于导航，不能替代详读；可用文内链接连接两层。

## 四、自定义

严格沿用用户给出的主标题与顺序，内部子标题按实际需要设置。不擅自把某个用户示例变成所有人的默认。

可使用的自定义结构示例：
全文总览 → 变量拆解 → 理论模型 → 结果分析 → 结论。

变量拆解说明X、Y及实际存在的中介、调节、控制、代理或机制变量。没有正式中介时明确说明，不能因为模板含“中介”就将普通控制变量指定为中介。
理论部分按原文实际层级解释：自建形式模型、借用理论、口头经济机制或实证方程可以分别呈现；不为口头机制创造“原文理论模型”。

## 共同深度

笔记开头简要标注题名、作者及可核实的发表信息、源文件、已读范围、附录获取状态和输出结构。元数据缺失保留未知。

每个关键方法说明：处理什么问题、输入与输出是什么、计算或推导怎样进行、为什么采用该步骤、需要哪些条件。
每个核心变量说明：经济概念、观测层级、原始字段、公式、聚合与标准化、时间对应、筛选和单位。
每个关键公式说明：原式、符号、条件、逐步运算或推理、经济含义；讲解添加的假定数值明确标注。
每个关键结果说明：模型或组合设计、列和行、系数或差值、统计量、单位、经济量级、稳健性及支持范围。

核心图表保留原图和完整图注/表注，或准确转录可读内容，并紧邻解释。必要时局部裁剪；无法处理的图表明确限制，不声称已经看过。
结论部分区分作者结论与阅读评价。阅读评价可以分析证据和局限，但不写后续追问、讨论菜单或研究启发。

## 中文解释

用户要求中文精读笔记时，对照的是本次精读讲解。英文原文术语与中文说明保持稳定，公式共用、符号不翻译。少量关键原句可与解释对照并标出来源；不要把自行撰写的英文讲解冒充原文引文。
默认提供中文精读解释；原文中的英文术语可附中文说明。精读笔记应保持完整讲解，避免变成只摘录原文的对照表。
