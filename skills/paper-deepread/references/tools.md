# 工具与失败处理

## 可替换的最低能力

宿主需要读取用户材料，输出Markdown；分析关键视觉证据时还需PDF渲染或图像查看。补充外部知识时使用宿主已有公开检索工具。已有工具优先，不依赖其他Skill、特定MCP、付费API或固定模型。

本包辅助脚本使用Python 3.10+：
- prepare_pdf.py：pdfplumber优先，pypdf作为替代；至少一个可用。逐页提取文本和真实页行定位，生成读取信号与来源清单。
- render_pdf.py：pypdf、Pillow及系统PATH中的pdftoppm，或通过--poppler传入其实际路径。页面与裁剪坐标以渲染页面左上角为原点、PDF点为单位。
- check_markdown.py：仅Python标准库，检查本地链接、资源和数学分隔符及括号。不是科学事实验证器。

缺库时先使用宿主已有PDF能力；不要因为可替换的脚本无法运行而中止可读材料分析。必要安装遵循环境权限，不自动添加服务或改宿主配置。跨宿主迁移时发现实际解释器和工具位置，不硬编码开发机路径。

## 调用示例

在已定位的Skill根目录执行，或使用脚本绝对路径；输入和输出路径包含空格时按当前shell规则引用：

```text
python scripts/prepare_pdf.py "paper.pdf" --out "_source"
python scripts/render_pdf.py "paper.pdf" --page 4 --out "assets/page_04.png"
python scripts/render_pdf.py "paper.pdf" --page 4 --bbox 40 60 510 430 --out "assets/table_01.png"
python scripts/check_markdown.py "精读笔记.md" "论文延展.md"
```

prepare_pdf.py生成paper_text.txt和source_manifest.json，保留原PDF路径与SHA-256，不复制原件。文本中的P页码-L行号只适用于这个确实生成的提取版本；清单提供页数和各页信号。不要宣称它识别出了全部公式、表格或原文印刷页。

渲染与裁剪文件需要实际查看。渲染成功不意味着视觉核查完成；自动提取成功也不意味着数字、公式、排版或阅读顺序正确。

## 失败降级

- 未找到或无法打开PDF：报告具体原因；不根据标题生成论文正文细节。
- 混合PDF或扫描件：列出不可读页，完成可读范围并说明缺失材料；可请用户提供可复制文字的版本。不能把空提取视为论文无内容。
- 缺附录：正文能读就继续；附录相关定义或结果标明未核查，只有问题必须依赖它时才补问。
- 无法渲染：利用已有页面图像或替代工具；仍无法核对时说明哪些公式或表格的解释不确定。
- 无法联网：从本地原文回答，外部背景与创新性保留待验证。
- 仅局部文本：按局部材料范围答疑，不伪装完整精读。
- 输出目录无权限：先完成不受影响的分析，按宿主规则处理写入问题，不能默默换到无关目录。

检查脚本以退出码1表示机械错误，退出码0仅表示所检查项目未发现错误。对不能自动可靠判定的项目输出提示，交付前仍需人工源核对。
