# 工作模式与范围

局部改编 nature-skills 的compose及partial-scope方法，2026-10-05修改；来源见 ../PROVENANCE.md。

| 请求 | 行为 | 交付 |
|---|---|---|
| 只有题目/方向 | 提出中心问题、机制分解、任务与数据条件，默认先框架 | 研究框架.md；等讨论确定再扩写 |
| 明确完整初稿 | 直接按可得证据写完整初稿，条件不足标待补 | 计划书初稿.md |
| 指定章节修改 | 只改指定范围，维持其余文本和已定术语；范围外矛盾另列建议 | 修改稿及简要修改说明 |
| 补写/重构 | 填入缺失章节，保留约定总问题、模板和导师约束；连带修改如属请求则执行 | 补写稿或重构稿与说明 |
| 审查/评估 | 定位问题、缺证据、识别风险与承诺越界，不自动重写全文 | 审查意见.md |

模式不是强制顺序。直接完整初稿请求不需要再设置框架批准关卡。用户只要求讨论、不写文件时尊重范围；给定仅一阶段/子课题时不扩写后续阶段。已有框架批准不等于团队、数据和资源已被验证。

从题目开始时先识别现实问题与可回答的学术问题，不把“研究AI赋能金融”当作足够具体的问题。可提出选择，但有已确定默认时直接执行；需要用户提供的事实列待补。若用户要求只用给定材料，遵守，不擅自联网。混合多个版本时列冲突并保持用户明确选择的基准版本。
