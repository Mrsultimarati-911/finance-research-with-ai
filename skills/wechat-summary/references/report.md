# 报告与证据规范

默认文件名 `<主题>_公众号资料总结.md`，中文、一份 Markdown，固定五章。先逐篇摘要，再从实际已读材料综合。内容深度随来源调整，没有证据的项目说明未获得，不凑数。

## 1. 检索范围与获取情况

列出任务、账号、执行日期与闭区间、主题词与扩展词、实际工具、已调用页码及状态。区分原始结果行数、候选、已核对合格材料、正文已读、官网对应来源、失败、待核实和未处理。写清楚停止原因与公开索引覆盖限制，不宣称自动穷尽或跨账号批量任务已经完成。

## 2. 逐篇详细摘要

每篇使用稳定编号如 `[A01]`，覆盖：

1. **文章信息与读取状态**：标题、作者、实际发布主体、日期、微信/发现/实际读取链接、原创或转载情况、元数据核对依据与可见范围。
2. **主要观点**：中心问题及作者判断，按文章逻辑解释。
3. **论证依据**：机制、政策、研究或案例如何支撑结论，定位到正文小节、段落或图号。
4. **关键数据或案例**：时间、单位、样本、分母及口径；缺失信息明确标注。
5. **图表解读**：图号或图片索引、坐标和范围、能够支持的结论及局限，必要图片放在对应解读附近。
6. **与主题的关系**：回答主题中的哪一问题，以及贡献和边界。

只写实际已读材料。仅有标题或搜索片段的候选列在第五章，不写正文摘要。没有关键图表时据实说明，装饰图不当作支撑证据。文章身份和转载共同来源分别核对，不按题名合并。

## 3. 主题综合报告

组织实际已读文章的共识、分歧、机制、脉络和证据强弱，主要判断关联文章编号、原文位置或外部核实记录。明确区分：

- **作者观点**：作者或机构提出的判断。
- **原文证据**：文中陈述的数据、研究和案例，尚不自动等于独立事实。
- **已核实事实**：追溯原始来源后确认的具体命题，带核实限制。
- **综合分析**：本报告据材料提出的解释，说明推断链和边界。

同一数字、政策或论文的转载次数不能当作独立证据数量。证据不足时缩小判断，不把获取失败写成观点缺失或行业没有相关情况。

## 4. 金融研究与课题论证背景

整理现实问题、金融机制、变量和数据线索、研究缺口与潜在问题。区分来源已经提出的研究与本报告提出的可检验构思，注明数据可得性、识别假设及待补部分；不声称已完成实证研究或完整课题可行性论证。

## 5. 来源与核实情况

给出来源账本及“命题—原文位置—原始来源—核实结果—限制”表。结果可为已核实、部分核实、未核实或存在冲突。关键图注明索引和原 URL，转载关联共同来源。单独列失败、待核实和未处理清单。

微信受限、官网可见正文已读时，保留两侧状态并注明实际读取 URL、同文核对依据和未确认部分。官网网页日期不直接替代微信日期。关键政策、数字和论文只取得摘要或部分内容时据实说明。

## 交付检查

检查主要判断能否定位来源、链接和必要图片是否可用、单位与时期是否一致、已发现材料是否均有摘要或处置理由，以及是否把搜索片段或受限微信当成已读。全部失败也保留五章，第二至四章说明证据不足，不生成无来源分析。
