# 收集与阅读流程

## 确定范围与记录检索

记录执行日、Asia/Shanghai 时区、日期闭区间、账号原称与确认名称、主题解释、查询词及实际工具。默认向前一个日历年，不等同固定 365 天；用户明确指定日期时优先使用。

宿主逐账号、逐查询词调用 `search_articles`。第一页从 1 开始，返回 `has_next` 后由宿主决定继续调用下一页，保存实际页码、状态和候选。可围绕初搜结果扩展同义词、相关概念或准确题名，也可用宿主已有公开搜索补充发现。不要把调用一次写成所有账号或全部分页已完成。

记录为什么结束：当前可访问分页已读完、相关查询暂未产生可核实的新材料、用户范围已满足，或工具/网络/资源受限。不要把有限词表、空搜索或失败称为自动饱和、完整历史或已穷尽。检索行数、候选数和成功读取材料数分别统计。

## 账号、日期与文章关系

- 搜索账号字段做初筛，结合原始页面或已核实官网机构作最终判断。同名、简称或标题提及均不足以确认身份。
- 原始发布日期优先，搜索日期与正文冲突时保留双方信息及采用依据。官网日期不能未经依据代替微信日期；未知日期保留待核实。
- 文章 ID、微信 `__biz/mid/idx`、短链接和规范化链接可用于检查重复，搜狗索引标识只作暂时线索。由宿主结合原页与元数据核对，不承诺工具自动完成可靠身份识别或最终去重。
- 不按标题删除候选。同标题可能是不同文章；转载保留自身身份，并标记共同政策、统计、研究或原文章来源，综合时不重复计为独立证据。

所有实际发现且核对符合账号、日期和主题范围的材料进入处理队列，没有预设总篇数。尚未读取或核实的候选列出理由，不能静默用前 N 篇代表全部。

## 正文与图表

逐次调用 `read_article(url)`，记录标题、作者、发布主体、日期、发现链接、微信链接、实际读取 URL、可见范围和警告。元数据缺失或疑似错误时结合原页检查。`text_available` 不保证全文完整，`images_only` 需要读图；搜索片段、网页提示或推荐列表不能冒充正文。

根据正文引用和图片清单选择关键图表，调用 `read_article_images`。索引从 0 开始，第十一张为 `start=10`，每批 `count` 为 1–8，批次大小不限制总图数。图片块与元数据中成功条目顺序对应；宿主必须实际提供图片给视觉模型，元数据成功不能算完成解读。

核对图表标题、轴、单位、分母、时期、样本、来源及注释，区分相关性、预测和观测。只保存报告需要的关键图表，附原 URL 和索引；装饰图无需保存。不可读处明确标注，不猜数。全部音视频嵌入均忽略，不调用下载、转写或关键帧工具。

文章多时按批完成自己写的摘要、来源账本及剩余队列，再继续。资源不足时交付已读部分及未处理清单，不宣称批量任务已全部完成。

## 官网对应文章

先核对官网所属机构，再检查标题、作者、日期、转载标记、公众号来源说明、微信链接及可对应正文。只有相似主题时不能当同文。微信无法读取、无法逐字比对时，写清楚对应依据与未确认部分，不声称全文一致。

分别记录微信访问情况、发现链接和实际读取官网 URL；读取工具返回 `public_web` 不代表已认证同文。没有对应公众号条目的官网文章可明确作为外部背景来源，不增加公众号已读篇数。

## 核实与交付

主要政策、数字和论文结论优先追溯官方文件、统计发布或论文出版页，检查适用时期、对象和统计口径。只取得摘要时注明摘要核对，无法确认时保留为原文声称。无 DOI 不编造 DOI。

依据 [报告规范](report.md)交付固定五章。来源状态、警告及原页需要共同核对，不能保证访问限制被稳定分类。可能受阻时记录实际情况，停止受限路径；失败不等于没有文章。只保存报告、必要图片和来源记录，不保存公众号全文或 HTML 档案。
